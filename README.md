# Sophie Bluel

Projet réalisé dans le cadre de ma formation Développeur Web chez OpenClassrooms.

L'objectif du projet était de rendre dynamique le site portfolio d'une architecte d'intérieur en développant des fonctionnalités en JavaScript et en communiquant avec une API existante.

## Objectifs

- Récupérer et afficher dynamiquement les projets depuis une API.
- Mettre en place un système de filtres par catégorie.
- Développer une page de connexion administrateur.
- Permettre l'ajout et la suppression de projets depuis une modale.
- Manipuler le DOM avec JavaScript.
- Communiquer avec une API via des requêtes HTTP.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- API REST

## Fonctionnalités principales

- Affichage dynamique de la galerie de projets.
- Filtres par catégories.
- Authentification administrateur.
- Ouverture et gestion d'une modale.
- Ajout d'un nouveau projet.
- Suppression d'un projet.
- Mise à jour dynamique de l'interface.

## Architecture du projet

Le dépôt contient deux parties :

- `FrontEnd` : interface du site et logique JavaScript.
- `Backend` : API fournie pour le fonctionnement du projet.
